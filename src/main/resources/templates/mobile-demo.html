📖 Hướng dẫn sử dụng

  1. Nhấn vào nút ☰ Hamburger để mở Sidebar
  2. Nhấn vào icon 🔍 Search để mở thanh tìm kiếm
  3. Xem 🛒 Giỏ hàng với badge số lượng
  4. Thử resize trình duyệt để xem responsive
  5. Trên desktop (>= 1024px), header truyền thống sẽ hiển thị

🔧 Tích hợp vào project

1. CSS đã được thêm vào head.html

<link rel="stylesheet" th:href="@{/assets/css/mobile-layout.css}"/>

2. JS đã được thêm vào head.html

<script th:src="@{/assets/js/mobile-layout.js}"></script>

3. Thay thế header trong template

<div th:replace="~{shared/fragments/responsive-header :: responsiveHeader}"></div>
